# 一些小技巧

在共享/远程实验室服务器上干活时攒下的一些小技巧，每篇都是独立、可直接上手的短教程。

## 如何愉快的配置内网服务器代理上网

内网服务器连不上外网（GitHub、HuggingFace、pip 源）？用 `http_proxy` 借助 Clash 等代理软件让它通外网，含临时/永久配置、内网排除和排查。

## 如何愉快的使用 tmux 在服务器后台跑任务

关掉终端任务就没了？tmux 让任务跑在独立会话里，随时断开重连。含核心工作流、命令速查表和配置优化。

## vscode & cursor & windsurf 如何远程 debug 代码

告别 `print` 调试。用 `debugpy` 在本地编辑器里给服务器上运行的代码打断点、单步、看变量。

## 让 cursor 更聪明

一段可直接喂给 Cursor / Windsurf / Claude Code 的人格设定提示词，把 AI 调教成会从第一性原理拆解问题的资深工程师搭档。
